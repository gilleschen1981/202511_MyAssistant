# Timer Sound Assets

## Required Audio File

Place a timer completion sound file named `timer_complete.mp3` in this directory.

### Recommended Sound:
- Format: MP3 or WAV
- Duration: 2-5 seconds
- Volume: Medium to loud

### Where to get free timer sounds:
1. [Pixabay Sounds](https://pixabay.com/sound-effects/search/timer/) - Free timer sound effects
2. [Freesound](https://freesound.org/) - Free sound library
3. [Zapsplat](https://www.zapsplat.com/) - Free sound effects

### Example:
Download a timer bell or alarm sound and save it as `timer_complete.mp3` in this directory.

If no audio file is provided, the app will use device vibration as fallback.
